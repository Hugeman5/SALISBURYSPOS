# **App Name**: ZA-POS

## Core Features:

- PIN Login: Implement a PIN login system with role-based authentication (admin, manager, cashier, waiter, kitchen).
- Admin Dashboard: Admin dashboard to manage users, roles, and system settings.
- User & Role Management: User management interface to add, edit, and disable user accounts, including role assignment.
- Time Clock: Digital time clock to record employee work hours. Time clock uses the roles that were setup.
- Menu & Recipes: Menu and recipe management system, that calculates the cost.
- Table Plan: Intuitive table plan interface to manage tables and seat customers.
- AI Meal Pairing Suggestions: Suggest popular meal pairings based on current orders using a reasoning tool.

## Style Guidelines:

- Primary color: Vibrant Orange (#FF7800) to reflect South Africa's vibrant culture and energy.
- Background color: Dark gray (#222222) to provide a modern, sleek look, in keeping with Lightspeed POS
- Accent color: A vivid lime green (#32CD32) for interactive elements and highlights.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a neutral look.
- Use minimalist and clear icons for easy navigation. Consider using the 'lucide-react' library set in the package.json.
- Maintain a clean and organized layout. Prioritize key functions such as order taking and payment processing.
- Subtle transitions and animations for feedback, but keep it minimal to maintain speed and efficiency.
